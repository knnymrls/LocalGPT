# 0010 Consistent clear glass

Date: 2026-10-03

## Decision

Kenny requested more transparent glass and pointed out the visibly different left button and right group. Both now use the same clear native glass and directional rim. The right capsule belongs to the system Menu label, while the Menu has plain button styling. New chat and Outputs retain independent tap targets.

This supersedes the native glass-button styling choice in decision 0006. Applying the shared surface inside the label avoids an additional native capsule fill. The menu itself remains the system component. Dark open/close footage was inspected without observing the earlier solid black flash; this is a bounded Simulator check.

Sheets retain native presentation and detents with a clear navigation-container background and a shared glass background at 55% opacity. Text and controls stay fully opaque. Background and presentation corners use one 40pt value. Reduce Transparency provides a solid system background.
