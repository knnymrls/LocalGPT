# 0012 — Editable conversation starters

Date: 2026-10-03

Show four examples in an empty chat: notes to actions, CSV expense tracker, PDF checklist, and budget chart. Each includes fictional input and a short capability description. Tapping fills the shared draft; Send runs the normal assistant. Do not seed fake assistant conversations, create artifacts on startup, or save demo facts to memory.

Keep example content in a small presentation catalog, separate from the list view. Use the same prompts for focused live checks. These examples demonstrate current text and artifact capabilities, without implying that OCR is full vision or that charts are generated pictures.
