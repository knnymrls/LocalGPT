# Product documents

- [PRD](prd.md): product requirements and acceptance criteria.
- [Design](design.md): visual rules and interaction states.
- [Architecture](architecture.md): ownership and service connections.
- [Change log](CHANGELOG.md): completed changes and observed status.
- [Decision records](decisions/): rationale, consequences, and unresolved choices.

The repository PRD is the versioned product document. The [planning Page](https://chatgpt.com/space/page_f04ee0dd1c3081919276da10e94b6ade) mirrors it for discussion. Keep the PRD focused on product behavior; implementation details belong in architecture and research notes.
